# Landing Page: Hospital de Alta Resolución de Roquetas (HTML, CSS, JS)

Proyecto de desarrollo web frontend que consiste en la creación de una *landing page* informativa para un hospital. La página es totalmente responsive, accesible y utiliza manipulación del DOM con JavaScript.

## 🛠️ Tecnologías y Herramientas
*   **Estructura:** HTML5 semántico
*   **Estilos:** CSS3 (maquetación, transiciones, hover, formularios)
*   **Interactividad:** JavaScript (manipulación del DOM, eventos)
*   **Validación:** W3C (HTML5 y CSS3)

## 🎯 Funcionalidades y Conceptos Aplicados

1.  **Estructura HTML5:**
    *   Uso de etiquetas semánticas: `header`, `nav`, `main`, `section`, `footer`.
    *   Formulario de contacto completo con diferentes tipos de `input` (texto, email, teléfono, fecha, hora, checkbox, radio, select, textarea).
    *   Tabla de horarios con celdas combinadas (`rowspan` y `colspan`).

2.  **Diseño CSS3:**
    *   Menú de navegación horizontal con efecto *hover*.
    *   Galería de imágenes con transiciones y efecto *zoom*.
    *   Diseño limpio y homogéneo usando una gama de colores (azules y blancos).
    *   Estilos personalizados para el formulario.

3.  **JavaScript (DOM):**
    *   Creación dinámica de un párrafo de bienvenida al cargar la página.
    *   Modificación dinámica del título de la sección "Horario" y sus estilos.
    *   Evento `onclick` en la lista de servicios para eliminar el último elemento al hacer clic.

4.  **Validación:**
    *   Inclusión de iconos de validación W3C para HTML5 y CSS3 en el pie de página.

## 🚀 Cómo visualizar el proyecto
1. Descarga los archivos (`index.html`, `style.css`, `script.js`) y la carpeta `img`.
2. Abre el archivo `index.html` en cualquier navegador web.
